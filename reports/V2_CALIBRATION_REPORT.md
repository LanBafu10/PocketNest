## 2. 新架构（全部通用规则，不含小家特例）

### 2.1 户型：像素级校准 + 门窗锁死
`floorplan_refine.py`

1. **白边外溢**：用「彩色地面/黑色墙线」前景掩码逐边收 bbox，最多收 22%；
2. **墙线吸附**：统计暗像素列/行得到强墙线，bbox 边缘吸到 55~72px 内最近的墙；重叠房间共用同一道墙；
3. **L 形公共区**：客厅吞掉卫生间/厨房 >35% 时裁大房间，并把被裁掉的连通条带保留为「过道」矩形（带 open_arch）；
4. **门洞锁死**：在 bbox 边缘 ±14px 的墙线带里找低暗度缺口，反算 `offset/width_m`；门标错墙时在其它墙找 0.5~1.35m 的合理缺口迁过去；
5. **顺序修正**：`snap_geometry()`（聚类+裁重叠）→ `_snap_door_walls()`（门缝合缝）→ `validate_rooms()`（门洞夹进共享墙、门窗连通性、覆盖率），门洞之后不再移动墙体；
6. **建筑规范**：移除卫生间↔厨房直开门，厨房门改为北偏西开向过道。

### 2.2 房间：以门为锚点的机位定标 + facing
`pipeline_room.py`

1. `calibrate_photo_orientations()`：户型图 + 本房间所有照片 + 四面墙门窗地图 → 逐张输出 `front/left/right/back` 与锚点证据；
2. pass1 把定标表原样塞进提示词，模型不再凭画面左右猜东南西北；
3. pass2 传入 `walls_desc` + 定标表，逐件复核 exists/duplicate/墙锚/尺寸/框，并新增强制字段 `facing`（`room_center` / `table` / 具体墙）；
4. `solve_room_layout()` 的朝向：餐椅按「朝餐桌中心」算角度；贴墙大件保持锚点 0/90/180/270，忽略 `room_center` 的斜角；桌/地毯强制轴对齐。

### 2.3 GLB 姿态：直角吸附
`aholo_client.calibrate_glb_pose()`

- 斜角搜索从 -44..45° 收窄到 **-8..8°**，只去轻微歪斜；
- L 型橱柜禁止 90° 翻转（按两条臂平行坐标轴对齐）；
- 象限只允许 0/90（按目标长宽比判断），不再用「法线盲猜」做 180° 翻转；
- 正背面最终由 2.4 的视觉闭环兜底。

### 2.4 多角度截图 + 自纠偏闭环
`pose_audit.py` + 前端 debug 参数

1. 前端：`?pid=..&debug_pose=1&view=top|iso|room&roomId=..&yaw=0|90|180|270`；3D 场景里画 N/E/S/W 罗盘、红/蓝/绿门洞条、每件家具的红色正前方箭头；
2. 后端：headless Chromium 自动截 top/iso + 每房 4 个方位（本轮 22 张）；
3. 确定性自检：餐椅朝桌、贴墙件正面离墙、轴对齐件不斜放；
4. VLM 复核：户型图 + top/iso + 四方位截图 + 2 张实景 → 只输出高置信度 patch（±90/180、facing），自动回写后复验；**VLM 必须显式返回 `pass=true` 才算通过**，截图无效/看不全一律 `pass=false`；3D 场景 90s 未就绪直接失败，不再截空图静默通过。

### 2.5 本轮驳回项的通用修复（无手调）

| 驳回项 | 通用修复 |
|---|---|
| 双侧 render_leaf=true 重绘门扇 | `validate_rooms` 按「房间对」去重共享平开门：先出现的 `render_leaf=true`，另一侧 `false`（只留门洞） |
| 同门高度随视图改变 | 前端固定 `DOOR_H = 2.02`，门楣切割与门扇都用同一常量，不再用 `isSingleFocus ? 1.98 : 1.22~1.52` |
| GLB 三轴非等比缩放 | `mountRoomFurniture` 改为 `uniformScale = min(tw/sx, th/sy, td/sz)`，`scale.setScalar` 等比缩放，禁止逐轴拉伸 |
| 主轴校正不能判正面 | `calibrate_glb_pose` 新增「高背侧」几何判据：床/沙发/马桶/书桌/椅子的高点在 +Z → 180°，在 ±X → 90/270°；L 型橱柜不做 90° 翻转 |
| 审图超时仍截图、无 patch 即结束 | `_capture` 超时抛错不截图；VLM 必须返回 `pass`；无 patch 且无 `pass=true` 记为 unverified，`report.ok=false` |
| 禁止手调 nest_test_v3 | 本轮用 `nest_test_v4`：从原 `nest_aebdace838dd` 复制数据后只调 `/floorplan/reparse` + `/build3d`，不手工改 project.json |

## 4. 阶段 2：网上公开户型泛化测试

来源：ArchDaily 公开文章《30 plantas de apartamentos de 20 a 50m²》中的 3 套不同格局平面图（仅用于本地测试）：

| 案例 | 类型 | 解析结果 | 耗时 | 主要警告 |
|---|---|---|---|---|
| studioWOK | 单层开间 | 5 空间：阳台 4.96×2.07、厨房 1.35×2.50、卫生间 1.77×1.96、玄关 1.16×1.96、起居 5.00×5.23 | 10s | 厨房西门/起居西门不在外墙（开间墙体未闭合） |
| A_Little_Design | Loft（图纸含两层） | 4 空间：LIVINGROOM 3.48×4.10、KITCHEN 1.65×2.40、BATHROOM 2.63×2.20、BEDROOM 3.54×6.50 | 8s | 客厅东门无相邻房间 |
| 3XA | 两层复式（图纸含两层） | 5 空间：玄关 1.15×1.17、客厅 3.92×3.45、厨房 0.96×1.26、卫生间 0.80×3.45、卧室 2.50×3.45 | 36s | 二审整体转置已丢弃；面积尺度差 1.51 倍已采信房间尺寸；多处门洞不连通 |

**迭代结论**：

1. 单层开间/一居室：墙线吸附 + 门洞缺口在灰度建筑图上同样有效，bbox 能贴墙；
2. **多层图纸**：当前把两层画在一张图上的案例当成单层解析，房间会跨层合并——这是下一轮要补的「楼层选择/图纸裁切」前置步骤；
3. 开间/无门洞的开放空间：门洞连通性警告较多，但不会崩；下一步应支持 `open_arch` 自动补全；
4. 面积尺度：3XA 的面积尺度与房间尺寸尺度差 1.51 倍，程序已按「房间尺寸」采信并告警；建议后续加「用户填面积」硬锚点。

## 6. 已知限制 / 下一步

1. **多层图纸**：需要先做楼层检测/裁切，再逐层解析；
2. **面积比例尺**：VLM 估算 0.012~0.016 m/px 波动，建议前端加「套内面积/某一面墙长度」输入作为硬锚点；
3. **开放空间**：L 形/无门垭口的走廊只做了「条带保留」启发式，复杂户型仍可能丢失；
4. **家具数量**：单次 VLM 清点会漏小件（本轮卫生间 5 件、厨房 2 件），可加「按类别清单二次补漏」；
5. **GLB 体积**：已用 `gltf-transform resize 512` 压到平均 ~3MB，后续可加 Draco/meshopt + 前端按房间懒加载。
